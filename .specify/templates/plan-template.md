## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

Each gate maps to a principle in `.specify/memory/constitution.md`. Mark each
PASS / FAIL / N/A and justify any FAIL in the Complexity Tracking table.

- [ ] **I. Multi-Model by Design** — Does this feature touch model loading or
      inference? If yes, all model-specific code stays behind the `ASRModel`
      interface; transport/UI/orchestration code does not import a
      model-specific package.
- [ ] **II. API and UI as First-Class Surfaces** — Any new HTTP endpoint is
      URL-versioned (`/api/vN/...`); checked-in OpenAPI schema is updated;
      UI is updated (or a follow-up issue is filed) so both surfaces stay in
      sync.
- [ ] **III. Pragmatic Test Discipline** — Critical paths added/changed by
      this feature have tests in the same PR (contract, error handling,
      transcription correctness as applicable).
- [ ] **IV. Layered Integration Testing** — For new endpoints or model
      registrations: contract test added; real-model smoke test added (if a
      model is added); containerized E2E covers the new flow; CUDA-presence
      behavior is exercised.
- [ ] **V. Full-Stack Observability** — New code emits structured logs with
      correlation IDs; new latency/error surfaces have metrics; new
      pipeline stages have OpenTelemetry spans.
- [ ] **VI. Performance with Enforced SLOs** — Feature does not regress RTF,
      API overhead, cold-start, or steady-state memory beyond the 10%
      threshold. If it does, an SLO amendment PR is filed.
